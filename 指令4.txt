# 一、不可改变的 metadata 规则

继续保持：

```text

A  = edit_image[0]
B  = edit_image[1]
```

要求：

2. 只读取 `edit_image[0]` 和 `edit_image[1]`。
3. `edit_image[2:]` 完全忽略。
4. 四图 metadata 中的 focus 图不得被检查、打开或输入模型。
5. 训练和验证时 `image` 必须作为 GT。
6. 推理时 `image` 可以缺失。
7. 相对路径以 metadata.json 所在目录解析。
8. 支持 Windows、Linux、UTF-8 和 UTF-8 BOM。
9. A、B、GT执行同步几何预处理。
10. 当前不要求输出恢复到原始尺寸。

不要重新设计公共 metadata schema。

# 三、修复 SwinFusion：恢复官方单通道 Y 训练

处理目录：

```text
D:\focus_exp\baselines\SwinFusion
```

当前错误：

```python
opt["n_channels"] = 3
opt["netG"]["in_chans"] = 3
```

但官方 `loss_mff.py` 的 Sobel 卷积核是：

```python
[1, 1, 3, 3]
```

只能处理单通道输入。

因此必须取消 metadata RGB 三通道 SwinFusion 训练，恢复官方单通道 Y 流程。

## 1. 模型配置

在 SwinFusion MFIF 路线中固定：

```python
opt["n_channels"] = 1
opt["netG"]["in_chans"] = 1
```

不得为了 RGB 输入修改 `loss_mff.py`。

不要：

* 将 Sobel 改成 depthwise RGB；
* 对三个通道分别计算后平均；
* 修改官方 MFF loss；
* 修改模型第一层为三通道并继续加载官方单通道权重。

## 2. metadata RGB 转 Y

metadata公共读取仍返回 PIL RGB。

在 SwinFusion专用 Dataset adapter 中，将 A、B、GT转换到 YCbCr。

推荐使用 PIL：

```python
ycbcr = image.convert("YCbCr")
y, cb, cr = ycbcr.split()
```

训练模型输入：

```text
A_Y
B_Y
GT_Y
```

要求：

* A、B、GT先执行同步几何变换；
* 几何变换完成后再提取 Y，或保证 Y/Cb/Cr同步；
* 训练 tensor 为单通道 `[1,H,W]`；
* 数值范围与官方 SwinFusion一致；
* 不把 RGB 三通道输入单通道模型。

## 3. SwinFusion训练目标

继续保留官方：

```text
G_lossfn_type = mff
```

也就是说训练 loss仍由 A_Y、B_Y和融合 Y计算。

GT_Y用于：

* 验证 PSNR/SSIM；
* 结果配对；
* 可视化对照。

GT不得被错误描述成官方MFF loss的监督目标。

README和报告中写明：

```text
SwinFusion preserves its official single-channel luminance
training protocol. Metadata RGB images are converted to Y.
The GT luminance is used for validation, while the original
MFF source-based loss is preserved for training.
```

## 4. 推理色度恢复

SwinFusion输出只有融合 Y。

保存 RGB结果时使用 A 的 Cb/Cr：

```text
output_Y + A_Cb + A_Cr → RGB
```

建议：

```python
merged = Image.merge("YCbCr", (pred_y, a_cb, a_cr))
rgb = merged.convert("RGB")
```

要求：

* 色度来自 A；
* 不从 B复制色度；
* 不随机生成色度；
* 输出以 RGB PNG保存。

## 5. checkpoint模式

统一 SwinFusion推理模式，不再使用容易误导的：

```text
metadata-rgb
```

改成：

```text
official-y
metadata-y
```

语义：

### official-y

* 加载作者官方单通道 MFIF checkpoint；
* 使用 RGB→Y；
* 模型输出 Y；
* 使用 A 的 Cb/Cr恢复 RGB。

### metadata-y

* 加载本项目 metadata Y训练得到的单通道 checkpoint；
* 数据流程与 official-y相同；
* checkpoint应带本项目 data contract。

如果为了兼容旧参数需要保留：

```text
official
```

可以作为 `official-y` 的别名。

删除或禁止：

```text
metadata-rgb
```

除非仓库中确实已有经过验证的 RGB SwinFusion模型，但本次不要继续维护该路线。

## 6. SwinFusion data contract

# 四、继续修复 SwinFusion GPU逻辑映射

文件：

```text
baselines\SwinFusion\utils\utils_option.py
```

当外部存在：

```bash
CUDA_VISIBLE_DEVICES=1,2,3
```

时：

1. 不得覆盖环境变量；
2. 内部逻辑卡必须重映射为 `[0,1,2]`；
3. `num_gpu=3`。

实现：

```python
external = os.environ.get("CUDA_VISIBLE_DEVICES")

if external:
    visible = [
        value.strip()
        for value in external.split(",")
        if value.strip()
    ]

    if not visible:
        raise ValueError(
            "CUDA_VISIBLE_DEVICES is set but contains no valid devices"
        )

    opt["gpu_ids"] = list(range(len(visible)))
    opt["num_gpu"] = len(visible)

    print(f"[GPU] CUDA_VISIBLE_DEVICES={external}")
    print(f"[GPU] logical_gpu_ids={opt['gpu_ids']}")
    print(f"[GPU] num_gpu={opt['num_gpu']}")
else:
    configured = [
        str(value)
        for value in opt.get("gpu_ids", [])
    ]
    configured_string = ",".join(configured)

    if configured_string:
        os.environ["CUDA_VISIBLE_DEVICES"] = configured_string

    opt["num_gpu"] = len(opt.get("gpu_ids", []))
```

测试：

```bash
CUDA_VISIBLE_DEVICES=2
CUDA_VISIBLE_DEVICES=1,3
CUDA_VISIBLE_DEVICES=0,1,2
```

分别确认内部卡数为1、2、3。

# 六、修复 ReDiffuse 的硬编码 cuda:3

处理：

```text
D:\focus_exp\baselines\ReDiffuse\Diffusion.py
D:\focus_exp\baselines\ReDiffuse\train.py
D:\focus_exp\baselines\ReDiffuse\infer_metadata.py
```

当前错误：

```python
device = "cuda:3" if torch.cuda.is_available() else "cpu"
```

扩散系数可能被放到 `cuda:3`，而模型和数据在 `cuda:0`。

必须彻底删除对全局硬编码设备的依赖。

## 1. 修改 `_extract`

将类似：

```python
out = a.to(device).gather(0, t)
```

改为：

```python
def _extract(self, a, t, x_shape):
    out = a.to(
        device=t.device,
        dtype=torch.float32,
    ).gather(0, t)

    return out.reshape(
        t.shape[0],
        *((1,) * (len(x_shape) - 1)),
    )
```

要求：

* 设备来自 `t.device`；
* 不依赖模块全局 `device`；
* 支持CPU、单GPU和映射后的逻辑GPU。

## 2. 随机噪声

不要：

```python
torch.randn(shape, device=global_device)
```

改为：

```python
torch.randn_like(source_image)
```

或者：

```python
torch.randn(
    source_image.shape,
    device=source_image.device,
    dtype=source_image.dtype,
)
```

## 3. timestep

创建 timestep时使用输入设备：

```python
t = torch.randint(
    0,
    diffusion_steps,
    (batch_size,),
    device=target.device,
    dtype=torch.long,
)
```

## 4. 删除训练端临时猴子补丁

如果当前 `train.py` 或 `infer_metadata.py`存在：

```python
diffusion_module.device = device
```

在 Diffusion彻底设备无关后，应删除该依赖。

可以暂时保留兼容，但核心逻辑不得再读取全局device。

## 5. 设备测试

至少测试：

```text

CUDA_VISIBLE_DEVICES=1,3 → 单进程默认 cuda:0
```

确认没有任何：

```text

```

硬编码残留。

执行：

```bash

```

结果必须为空，README历史文本除外。

修改逻辑：

```bash
prepare_new_output() {
    local out="$1"

    if [[ -e "$out" ]] && [[ -n "$(ls -A "$out" 2>/dev/null)" ]]; then
        echo "[ERROR] Output directory is not empty: $out" >&2
        exit 3
    fi

    mkdir -p "$out"
}
```

对于新训练：

```bash
if [[ -z "${RESUME:-}" ]]; then
    prepare_new_output "$out"
fi
```

对于resume：

```bash
if [[ -n "${RESUME:-}" ]]; then
    [[ -f "$RESUME" ]] || {
        echo "[ERROR] Resume checkpoint not found: $RESUME" >&2
        exit 3
    }

    mkdir -p "$out"
fi
```

要求：

* resume允许目录已有日志和checkpoint；
* 不删除已有内容；
* 不清空目录；
* 不覆盖其他实验目录；
* 日志打印resume checkpoint和output dir。
