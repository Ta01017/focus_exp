# 一、绝对不能改变的 metadata 数据契约

metadata.json 顶层是 list，每个样本可能为：

```json
{
  "image": "images/000001_target.png",
  "edit_image": [
    "images/000001_a.png",
    "images/000001_b.png",
    "images/000001_focus_a.png",
    "images/000001_focus_b.png"
  ],
  "prompt": "Fuse two images with different focus into a single all-in-focus image.",
  "seed": 123,
  "source_dataset": "custom_dataset",
  "source_index": 1
}
```

统一解释：

```text
GT = image
A  = edit_image[0]
B  = edit_image[1]
```

必须遵守：

1. `edit_image` 至少包含两张。
2. `edit_image[0]` 是 A。
3. `edit_image[1]` 是 B。
4. `edit_image[2:]` 永远忽略。
5. 不得把 focus map 输入这些 baseline。
6. 四图或更多图时，只能读取前两张。
7. 推理时 `image` 可以不存在。
8. 训练和验证时 `image` 必须存在。
9. 训练时不能用 A 或 B 冒充 GT。
10. 相对路径以 metadata.json 所在目录为基准。
11. 支持 Windows 路径、Linux 路径、相对路径。
12. 支持 UTF-8 和 UTF-8 BOM。
13. 不根据文件名猜测 A、B、GT。
14. 后两张 focus 图即使路径不存在，也不应影响运行，因为它们必须完全不解析、不检查、不打开。

# 二、统一使用 RGB 数据契约

本项目所有 metadata 训练和 metadata 推理统一使用 RGB：

```text
通道0 = R
通道1 = G
通道2 = B
```

图像读取统一遵循：

```python
Image.open(path)
ImageOps.exif_transpose(image)
image.convert("RGB")
```

训练和推理必须保持：

* 相同通道顺序；
* 相同数值范围；
* 相同 normalization；
* 相同 A/B 条件排列；
* 相同输出反归一化；
* 输出以 RGB PNG 保存。

禁止：

```python
image[..., ::-1]
```

禁止：

```python
cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR)
```

禁止为了兼容作者旧目录 Dataset，将 metadata 数据转成 BGR。

本项目的正式 checkpoint 均来自 metadata RGB 训练链路，并配套 metadata RGB 推理链路。

如果某个作者官方 checkpoint 的颜色契约不明确：

* 可以进行兼容性诊断；
* 不得静默混用；
* 不得称作本项目 RGB 重训权重；
* 正式实验优先使用 metadata RGB 从头训练所得 checkpoint。

## 3. 新增准备脚本

新增：

```text

```

功能：

1. 检查解释器为 CPython；
2. 检查 Python版本为3.8；
3. 检查源pyc存在；
4. 检查pyc magic number；
5. 计算SHA256；
6. 复制为：

```text

```

7. 导入模块；
8. 打印实际加载路径；
9. 失败时明确退出。

实现参考：

```python
from __future__ import annotations

import hashlib
import importlib
import importlib.util
import platform
import shutil
import sys
from pathlib import Path


def main() -> None:
    repo_dir = Path(__file__).resolve().parent
    package_dir = repo_dir / "Condition_Noise_Predictor"

    source_pyc = (
        package_dir
        / "__pycache__"
        / "B_Conv.cpython-38.pyc"
    )
    runtime_pyc = package_dir / "B_Conv.pyc"

    if platform.python_implementation() != "CPython":
        raise RuntimeError(
            "Official B_Conv bytecode requires CPython."
        )

    if sys.version_info[:2] != (3, 8):
        raise RuntimeError(
            "Official B_Conv bytecode requires CPython 3.8. "
            f"Current interpreter: {sys.version}"
        )

    if not source_pyc.is_file():
        raise FileNotFoundError(
            "Official B_Conv bytecode is missing: "
            f"{source_pyc}"
        )

    payload = source_pyc.read_bytes()

    if len(payload) < 16:
        raise RuntimeError(
            f"Invalid or truncated pyc file: {source_pyc}"
        )

    file_magic = payload[:4]
    runtime_magic = importlib.util.MAGIC_NUMBER

    if file_magic != runtime_magic:
        raise RuntimeError(
            "B_Conv bytecode magic does not match the "
            "current CPython interpreter. "
            f"file={file_magic.hex()} "
            f"runtime={runtime_magic.hex()}"
        )

    sha256 = hashlib.sha256(payload).hexdigest()

    shutil.copy2(source_pyc, runtime_pyc)
    importlib.invalidate_caches()

    module = importlib.import_module(
        "Condition_Noise_Predictor.B_Conv"
    )

    print(f"[B_CONV] source={source_pyc}")
    print(f"[B_CONV] runtime={runtime_pyc}")
    print(f"[B_CONV] sha256={sha256}")
    print(f"[B_CONV] python={sys.version}")
    print(f"[B_CONV] imported={module.__file__}")


if __name__ == "__main__":
    main()
```

7. 输出RGB PNG。
