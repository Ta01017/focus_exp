# 一、最终数据契约

所有方法继续兼容同一种 metadata.json：

```json
[
  {
    "image": "images/000001_target.png",
    "edit_image": [
      "images/000001_a.png",
      "images/000001_b.png",
      "images/000001_focus_a.png",
      "images/000001_focus_b.png"
    ],
    "prompt": "...",
    "source_dataset": "...",
    "source_index": 1
  }
]
```

唯一允许的解释：

```text
GT = image
A  = edit_image[0]
B  = edit_image[1]
```

必须满足：

1. `edit_image` 至少包含两项。
2. 只能读取 `[0]` 和 `[1]`。
3. `edit_image[2:]` 完全忽略。
4. 后两张 focus 图不解析、不检查存在性、不打开、不输入模型。
5. 四图样本中，即使 focus 图路径故意不存在，也必须正常运行。
6. 训练和验证时 `image` 必须存在。
7. 推理时 `image` 可以缺失。
8. 不能用 A 或 B 替代 GT。
9. 相对路径以 metadata 文件所在目录为基准。
10. 支持 Windows、Linux、UTF-8、UTF-8 BOM。
11. A、B、GT使用同步几何变换。
12. 当前暂时不要求恢复原始图像尺寸。

```python
    a = a.astype(np.float32)
    b = b.astype(np.float32)

    wa = np.abs(a - 128.0)
    wb = np.abs(b - 128.0)

    return (
        (a * wa + b * wb)
        / (wa + wb + 1e-8)
    )
```
