# 三、修改 ReDiffuse 推理入口

处理：

```text

```

新增参数：

```text

默认建议：

```

因为作者仓库自带的是官方 `model.pt`。

## 1. official-y 模式

要求：

```python
in_channels = 3
out_channels = 1
```

数据流程：

```text
metadata RGB A/B
→ 转YCbCr
→ 提取A_Y、B_Y
→ 扩散生成output_Y
→ 使用A的Cb/Cr恢复RGB
→ 保存RGB PNG
```

推荐：

```python
a_ycbcr = image_a.convert("YCbCr")
b_ycbcr = image_b.convert("YCbCr")

a_y, a_cb, a_cr = a_ycbcr.split()
b_y, _, _ = b_ycbcr.split()
```

模型只使用：

```text
A_Y
B_Y
```

推理结果：

```python
output_ycbcr = Image.merge(
    "YCbCr",
    (
        pred_y,
        a_cb,
        a_cr,
    ),
)

output_rgb = output_ycbcr.convert("RGB")
```

要求：

* 使用 A 的 Cb/Cr；
* 不使用 B 的色度；
* 不把官方模型改成RGB；
* 使用 `strict=True` 加载官方 `model.pt`；
* missing keys必须为空；
* unexpected keys必须为空。

## 2. metadata-rgb 模式

要求：

```python
in_channels = 9
out_channels = 3
```

数据流程：

```text
A_RGB
B_RGB
noisy_RGB
→ 输出RGB
```

加载本项目训练的完整 checkpoint。

必须检查：

```python
checkpoint["data_contract"]["dataset_format"] == "metadata"
checkpoint["data_contract"]["color_space"] == "RGB"
checkpoint["data_contract"]["model_mode"] == "metadata-rgb"
checkpoint["data_contract"]["in_channels"] == 9
checkpoint["data_contract"]["out_channels"] == 3
```

不符合则拒绝加载。

## 3. 禁止自动推断模式

不要通过权重文件名猜测。

用户必须明确选择：

```text
official-y
metadata-rgb
```

如果没有指定，可以默认 `official-y`，但日志必须打印：

```text

```

如果用RGB自训权重加载 `official-y`：

# 九、修复验证过程污染训练随机状态

处理：

```text
baselines/ImageFusion/FusionDiff/train.py
baselines/ReDiffuse/train.py
```

当前问题：

验证阶段调用：

```python
torch.manual_seed(...)
torch.cuda.manual_seed_all(...)
```

但没有恢复训练前随机状态。

推荐使用：

```python
from contextlib import contextmanager


@contextmanager
def preserve_rng_state():
    python_state = random.getstate()
    numpy_state = np.random.get_state()
    torch_state = torch.get_rng_state()

    cuda_state = None
    if torch.cuda.is_available():
        cuda_state = torch.cuda.get_rng_state_all()

    try:
        yield
    finally:
        random.setstate(python_state)
        np.random.set_state(numpy_state)
        torch.set_rng_state(torch_state)

        if cuda_state is not None:
            torch.cuda.set_rng_state_all(cuda_state)
```

验证调用：

```python
with preserve_rng_state():
    random.seed(val_seed)
    np.random.seed(val_seed)
    torch.manual_seed(val_seed)

    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(val_seed)

    run_validation(...)
```

或者使用：

```python
with torch.random.fork_rng(...):
```

但必须同时保护 Python 和 NumPy RNG。

要求：

* 验证过程可复现；
* 验证结束后训练随机状态完全恢复；
* 后续epoch不会重复使用相同训练noise序列；
* DataLoader shuffle随机性不被验证重置。

# 十一、修复 scheduler 保存顺序

处理：

```text
baselines/ImageFusion/FusionDiff/train.py
baselines/ReDiffuse/train.py
baselines/diffusion_checkpoint.py
```

当前问题：

checkpoint可能在：

```python
scheduler.step()
```

之前保存，导致resume后的scheduler比连续训练少一步。

统一epoch末顺序：

```text
完成训练epoch
→ 完成验证
→ 更新best_val_loss
→ scheduler.step()
→ 保存checkpoint
```

checkpoint中的：

```text
epoch
global_step
scheduler
optimizer
best_val_loss
```

必须对应epoch结束后的完整状态。

建议：

```python
if scheduler is not None:
    scheduler.step()

save_checkpoint(
    epoch=epoch,
    global_step=global_step,
    best_val_loss=best_val_loss,
    ...
)
```

不要在保存后再执行 scheduler.step。

# 十三、明确 checkpoint 保存语义

在：

```text
baselines/diffusion_checkpoint.py
```

写清楚：

```text
Checkpoint represents the complete state after:
1. epoch training,
2. validation,
3. best metric update,
4. scheduler step.
```

checkpoint至少包含：

```python
{
    "format_version": 3,
    "method": method_name,
    "model": model.state_dict(),
    "optimizer": optimizer.state_dict(),

    "epoch": epoch,
    "global_step": global_step,
    "best_val_loss": best_val_loss,
    "config": config,
    "data_contract": data_contract,
    "random_state": {
        "python": ...,
        "numpy": ...,
        "torch": ...,
        "cuda": ...
    }
}
```
