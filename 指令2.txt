# 四、为 SwinFusion 增加独立输出目录和明确初始化模式

当前问题：

SwinFusion 默认从：

```text
Model/Multi_Focus_Fusion/Multi_Focus_Fusion/models
```

自动寻找最新权重，并将新的 checkpoint 保存回同一目录。

这会：

* 污染官方 checkpoint；
* 不明确是从头训练、官方权重初始化还是断点续训；
* 后续运行可能静默加载上一次实验结果。

必须增加以下参数：

```text
--output-dir
--init-mode
--init-checkpoint-dir
--resume-dir
```

允许值：

```text
--init-mode scratch
--init-mode official
--init-mode resume
```

语义必须严格区分。

## 1. scratch

```text
--init-mode scratch
```

要求：

* 不加载任何 G、E 或 optimizer checkpoint；
* 模型随机初始化；
* checkpoint 保存到 `--output-dir`；
* 如果 output-dir 已存在且非空，默认拒绝启动，除非显式传入 `--overwrite-output 1`。

## 2. official

```text
--init-mode official
--init-checkpoint-dir path/to/official/models
```

要求：

* 只加载模型权重；
* 不加载旧 optimizer 状态；
* 不继承旧 iteration；
* 新 checkpoint 保存到独立 `--output-dir`；
* 日志明确打印加载的 G/E 权重路径。

## 3. resume

```text
--init-mode resume
--resume-dir path/to/previous/run
```

要求：

* 加载模型权重；
* 加载 optimizer 状态；
* 恢复 iteration；
* 后续结果继续写入该运行目录或指定的新 resume 输出目录；
* 不自动扫描官方模型目录。

禁止继续使用“搜索目录中最新文件”来隐式决定训练模式。

建议输出结构：

```text
outputs/train/swinfusion/
└── <tag>/
    ├── checkpoints/
    ├── logs/
    ├── options_resolved.json
    ├── train_manifest.json
    └── validation/
```

运行开始时保存完整配置和命令参数。

# 五、修复 SwinFusion 训练随机增强

检查：

```text
D:\focus_exp\baselines\metadata_training.py
```

当前训练随机种子类似：

```python
seed = self.seed + index
```

这导致同一个样本每个 epoch 永远使用完全相同的：

* crop；
* flip；
* rotation。

修改要求：

## 验证模式

验证继续保持确定性：

```python
sample_seed = self.seed + index
```

同一个样本重复读取必须完全一致。

## 训练模式

训练模式必须随每次访问变化，但 A、B、GT仍使用同一组变换参数。

推荐实现：

```python
import torch

worker_seed = torch.initial_seed()
sample_seed = (
    worker_seed
    + index
    + self._access_counter
) % (2**32)
```

不要使用全局 `random` 无约束状态。

更稳妥的实现可以：

1. 在 Dataset 中增加 `set_epoch(epoch)`；
2. 训练循环每个 epoch 调用；
3. 使用：

```python
sample_seed = (
    self.seed
    + self.epoch * 1_000_003
    + index * 97
    + worker_seed
) % (2**32)
```

验收要求：

* 同一个训练样本连续读取多次，crop/增强至少有机会不同；
* 同一次读取中 A、B、GT 的 crop坐标、flip、rotation完全一致；
* 验证样本重复读取结果完全一致；
* `num_workers=0` 和 `num_workers>0` 都可运行。

增加单元测试，不只检查 tensor shape，还要检查同步性和随机性。

# 六、修复 FusionDiff 和 ReDiffuse 的采样步数含义

涉及文件：

```text
D:\focus_exp\baselines\ImageFusion\FusionDiff\infer_metadata.py
D:\focus_exp\baselines\ReDiffuse\infer_metadata.py
```

当前错误做法：

```python
GaussianDiffusion(args.sampling_steps, beta_schedule)
```

这会根据 `sampling_steps` 重新构造噪声日程，并不是在训练好的 2000-step 模型上进行正确的少步采样。

当前正式模型训练配置是：

```text
T = 2000
```

在没有实现并验证 DDIM、timestep respacing 或 DPM-Solver 前，必须禁止任意改变采样步数。

修改为：

```python
trained_steps = int(config["diffusion_model"]["T"])

if args.sampling_steps is None:
    sampling_steps = trained_steps
else:
    sampling_steps = int(args.sampling_steps)

if sampling_steps != trained_steps:
    raise ValueError(
        "This checkpoint was trained with "
        f"T={trained_steps}. Current implementation does not "
        "provide verified timestep respacing or DDIM sampling. "
        f"Please use --sampling-steps {trained_steps}."
    )
```

构造 diffusion 时始终使用训练配置：

```python
diffusion = GaussianDiffusion(
    trained_steps,
    beta_schedule,
)
```

CLI中保留 `--sampling-steps` 只是为了显式校验，不得重新设计 schedule。

README中明确写：

```text
FusionDiff/ReDiffuse正式推理必须使用2000步。
少步采样尚未实现，不得通过直接修改T实现。
```

# 八、优化 train/val 重叠检查，不要解码整个数据集

检查：

```text
D:\focus_exp\baselines\metadata_training.py
```

当前 `warn_split_overlap()` 如果调用 `prepare_item()`，会实际打开并解码 A、B、GT。

对几千条数据会导致训练启动前重复读取大量图片。

新增纯路径解析接口，例如：

```python
def inspect_item_paths(
    item: dict,
    index: int,
    metadata_path: Path,
) -> dict:
    metadata_dir = metadata_path.resolve().parent

    edits = item.get("edit_image")
    if not isinstance(edits, list) or len(edits) < 2:
        raise ValueError(
            f"metadata index={index}: edit_image must contain at least 2 paths"
        )

    gt_value = item.get("image")

    return {
        "index": index,
        "sample_id": get_sample_id(item, index),
        "a_path": resolve_portable_path(edits[0], metadata_dir),
        "b_path": resolve_portable_path(edits[1], metadata_dir),
        "gt_path": (
            resolve_portable_path(gt_value, metadata_dir)
            if gt_value
            else None
        ),
        "source_index": item.get("source_index"),
    }
```

要求：

* 不调用 PIL；
* 不读取图片内容；
* 只检查 metadata字段和路径字符串；
* `edit_image[2:]` 不解析、不检查存在性；
* 即使 focus图路径不存在，也不能影响训练，因为它们必须被忽略。

重叠检查至少报告：

* train/val sample_id交集；
* GT路径交集；
* A路径交集；
* source_index交集；
* 各自样本数量。

默认只 warning，不直接中止；增加可选：

```text
--fail-on-split-overlap 1
```
